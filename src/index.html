Insert in this order

    Bouncing from Logic Pro

    • File > Bounce > Project or Section (⌘B), with the cycle area covering the whole song.
    • Destination PCM, File Format WAVE or AIFF, Resolution 24-bit, Sample Rate same as the project.
    • Normalize: Off. Dithering: None. Mode: Offline.
    • For a mix headed to mastering, bypass any limiter or Mastering Assistant on the Stereo Out first.
    • Make a reference comparable: use a lossless or high-quality file, not a YouTube rip.
